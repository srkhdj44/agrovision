# Agrovision
Web app that detects crop leaf diseases from a photo using deep learning model , with Grad-CAM explanations and
 guidance. Final year project 2, KICT, IIUM.

## Team
 - Afiqah Najla

## Run locally
1. `python -m venv venv`
2. `venv\Scripts\activate`
3. `pip install -r requirements.txt`
4. `python app.py`
5. Open http://127.0.0.1:5000
