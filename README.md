## Run locally
1. `python -m venv venv`
2. `venv\Scripts\activate`
3. `pip install -r requirements.txt`
4. `python app.py`
5. Open http://127.0.0.1:5000
   
## Tech stack
Python, Flask, Jinja2, HTML, CSS, JavaScript, TensorFlow, Keras (EfficientNetB0)
